## 已知问题

1. `get_financials` 当前不是 key 未读取，而是 FMP 返回 `HTTP 402`。
   - `.env` 中的 `FMP_API_KEY` 会被 gateway 启动时读取。
   - 402 大概率是当前 FMP API key / 免费套餐没有对应 endpoint 权限。

2. `web_search` 画布卡片还不够好。
   - 搜索本身成功，最终回答能引用搜索摘要。
   - Canvas 目前只显示 `WEB · SEARCH Searched` 和 query。
   - 需要让事件携带 search results 或在前端从可用 payload 中渲染结果列表。

3. Narration 还不是每个工具调用前必有。
   - 当前更像“每组工具调用前一条 progress narration”。
   - 如果产品要强约束“每次工具调用前都说一句”，需要继续收紧 harness/system prompt 或在 runtime 层补一个显式 step event。

4. Browser 测试时系统 Chrome 多出过一个 `Sign Up | LinkedIn` 后台标签页。
   - 尚未确认来源。
   - 可能来自网页搜索、TradingView 链接、Chrome 扩展或 Computer Use 点击副作用。

5. `.claude/worktrees/*` 曾被误跟踪成 gitlink。
   - 本次 commit 会从 git index 移除这些坏引用。
   - 本地目录不会删除。

## 本地启动

```bash
git clone --recurse-submodules git@github.com:hchen13/leek.git
cd leek
```

准备本地 `.env`，不要提交：

```bash
TUSHARE_TOKEN=...
FMP_API_KEY=...
LEEK_SEC_USER_AGENT="leek local dev your-email@example.com"
```

启动 gateway：

```bash
cargo build
./target/debug/leek serve
```

启动前端：

```bash
cd frontend/web
npm install
npm run dev -- --port 5173
```

打开：

```text
http://localhost:5173/
```
