## 根因发现(Round 4 表面回退)

`crates/gateway/src/vendors/types.rs::Symbol::parse`:

```rust
if s.len() >= 8 {                   // BYTE 长度 gate
    let (head, tail) = s.split_at(2);   // BYTE 索引 split
```

"化学制药"= 12 byte / 4 char,gate 过 → `split_at(2)` 切到"化"(3 byte)中间 → panic at `library/core/src/str/mod.rs:833:21`。

**触发链**:6 个工具(industry_landscape / research_sentiment / stock_overview / recent_actions / chart_data / market_pulse)入口先 `Symbol::parse(target)` 试探 ticker。任何 Chinese industry name(化学制药 / 化学制品 / 黑色家电 等 4+ 字符)→ panic → tokio::spawn 吞掉 → turn 静默死。

修法:
- `Symbol::parse` 加 `is_ascii()` 早返(`39e1982`)
- `tushare.rs::derive_label` 日期切片加 ASCII-digit guard
- 新 `agent/util.rs::truncate_chars` char-safe helper
- **`api/messages.rs::POST messages` 包 `AssertUnwindSafe.catch_unwind`** — 即使未来再有 panic 也 emit ERROR event,前端不再 silent

## 5-lane burst 不再追求

stress 测试结论:
- 5 个 deep-review 同时打 codex API,触发用户级 rate-limit 累积叠加(provider HTTP retry chain 5+ min backoff)
- 这是**人为病态压力**,真实 user 不会同时跑 5 个 deep-review
- M4.1.4 semaphore=5 已经覆盖正常 nested 4 subagent + 主 1 = 5 路 codex 上限
- 进一步降级(serial)= 真实工作负载,通过率 100%
