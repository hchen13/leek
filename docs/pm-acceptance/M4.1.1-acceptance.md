## 4 case 详细

### case 1:`stock_overview` 茅台 quick-screen(PASS)

`prompt`:`快速看下 600519 贵州茅台,用 quick-screen`

- **stop_reason** end_turn / **asst_len** 379 字
- **6 tool calls + 2 subagent events**(主 agent task delegate 给 quick-screen,后者只看到 stock_overview + market_pulse 两工具)
- 输出包含:实时报价 ¥1273.38 / 涨跌 / 市值 / PE TTM 19.28 / PB 5.89 / PS / 股息率 4.06% / MA5 1295 / MA20 1351 / RSI6 数值 — **facts-only**,只在最后一行下"先观望"判断(那是 agent reasoning)
- ✓ 一个 stock_overview default focus=overview 就拿到 6 节 dossier
- ✓ raw 数据没漏到 model_output

### case 2:`market_overview` 大盘整体(PASS · 1 polish gap)

`prompt`:`看一下当前 A 股大盘整体情况:三大指数、涨跌家数、主力资金流向、热门行业`

- **stop_reason** end_turn / **asst_len** 528 字 / **6 tool calls / 2 searches**
- **3 次** `market_overview(focus=snapshot default)` — agent 没切到 `capital_flow` / `extreme_movers` focus
- 输出:三大指数完整(上证 4134.75 -0.26% / 深成 15933.82 +0.36% / 创业板 4089.11 +1.14%)+ 用 codex builtin search 补"涨跌家数 / 资金"
- ⚠ **polish gap**:agent 不知道要换 focus 取涨跌家数。tool description 写了 `Examples: '涨停几家' → focus='extreme_movers'` 但 agent 没 follow。修法:`market_overview` default focus 输出末尾加 hint `"涨跌家数/资金/北向请用 focus='capital_flow'|'extreme_movers' 重调"`

### case 3:`research_sentiment` + `read_pdf` chain(PASS · token bucket work as designed)

`prompt`:`看一下卖方对 600519 茅台的最新看法 ... 然后用 read_pdf 把研报前 4000 字读出来`

- **stop_reason** end_turn / **asst_len** 2603 字 / **4 tool calls**
- 工具序列:**`research_sentiment` → `read_pdf`**(完美 chain,正是 dispatch 设计意图)
- ⚠ **`report_rc` 频限触发了**(`code=40203`)— **work as designed**:工具 surface `empty_dimensions: ['report_rc:throttled']`,agent 正确解读为 "不能把'0 条评级'理解为市场真的没有评级,是接口频限"。这是 ch4 "empty ≠ access fail" + ch7 "schema 让 model 诚实退出" 教科书表现
- read_pdf 中文 PDF 实测过关(worker 已验证茅台研报 8855 字 48.5% 非 ASCII)

### case 4:`recent_actions` 茅台 60 天事件(PASS)

`prompt`:`看 600519 茅台最近 60 天的公告、大股东增减持、分红送股`

- **stop_reason** end_turn / **asst_len** 954 字 / **2 tool calls**(1 次 recent_actions + 1 别的)
- 输出按时间倒序(2026-05-22 → 05-08 → 04-29 → 04-25)
- 公告分类清晰(股东会 / 回购 / 业绩说明会 / 季报)
- ✓ **facts-only**:没"利好/利空"判断
