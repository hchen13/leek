# M4.1.1 — A 股工具高层级重做 v3(facts-only,vendor 实测过)

> **Dispatch spec(2026-05-27)。** v1(原 M4.1)6 endpoint wrapper 设计违反 harness-engineering-skill ch4 "Build high-leverage tools, not endpoint wrappers";v2 加 compare_stocks 又违反"facts-only"原则(工具不该下判断)。**v3 是定稿**,基于两份 vendor 实测调研:
>
> - `M4.1-tushare-zombie-audit.md` — tushare 37 endpoint 实测,标出 5 个僵尸/半僵尸 + 限频陷阱
> - `M4.1-eastmoney-survey.md` — 东方财富 9 大领域 70+ endpoint 调研 + 北向资金 2024-08-19 政策性死亡 + PDF URL pattern
>
> 必读必读,vendor 选择 / 限频 / 参数陷阱全在那两份里。

## 设计原则(按 harness skill ch3 + ch4 + ch7)

1. **工具返客观事实,不下判断** — 没有"贵/便宜/超买/分歧大"等形容词。MA20/RSI 只返数值,agent 自己解读
2. **没有 compare_stocks** — 比较是 agent reasoning 的活;agent 调 `stock_overview` ×N 拿 facts 自己对比
3. **load-bearing facts top-of-context**(ch3 lost-in-middle)— markdown 顶部"关键数据"先放
4. **provenance 不允许丢**(ch3)— 每节末尾标 `数据来源: Tushare fina_indicator @ 2026-05-27`
5. **structured error 严区分 5 类**(ch4)— transient / validation / policy / permission / **empty(success,非 error)**
6. **token-efficient default + detail opt-in** — default ≤1500 tokens distilled markdown;raw JSON 走 canvas 不进 model_output
7. **schema 让 model 诚实退出**(ch7)— 数据缺时返 `empty_dimensions: [...]`,model 不触发 retry
8. **least privilege** — 每个工具只暴露 agent 真需要的能力,不暴露 vendor endpoint
9. **冲突保留不平均** — 多 vendor 同字段冲突,双方都列(带日期),不取中位

## 9 个 facts-only 工具(替 11 个 endpoint wrapper)

每个工具:
- **内部 fan-out** 并发调多个 vendor method(`tokio::try_join!`)
- 返回 **distilled markdown ≤1500 tokens default**,focus 参数 zoom 单节 ≤4000
- raw structured data 进 **canvas display_payload**,supply 给 M4.2 chart
- 描述 5 件套:Purpose / Inputs / Examples / Limits / Boundaries

### 1. `macro_indicators(focus?)` — 宏观经济 facts

```
Inputs:
  focus?: enum default "inflation"
  choices: inflation / growth / money / policy / calendar / intl_rates
```

| focus | vendor(tushare) | 返字段 |
|---|---|---|
| inflation | `cn_cpi`(近 24 月)+ `cn_ppi`(近 24 月) | CPI/PPI 同比 + 环比 + 累计同比 + 当月日期 |
| growth | `cn_gdp`(近 12 季)+ `cn_pmi`(近 24 月) | GDP YoY + 制造业 PMI / 非制造业 PMI |
| money | `cn_m`(近 24 月)+ `sf_month`(社融近 24 月)+ `shibor_lpr`(近 24 月) | M0/M1/M2 同比 + 社融增量 + LPR 1Y/5Y |
| policy | `npr`(国家政策库 latest 20) | 政策标题 + 发布日 + 发文单位 + 摘要 |
| calendar | `cn_schedule`(未来 14 日) | 数据名 + 公布日期 + 重要性 + 预期值 |
| intl_rates | `us_tbr` + `us_tycr` + `shibor` + `hibor` | 美 3M/10Y 国债收益率 + 中 Shibor 1W/3M + Hibor |

输出 markdown:顶部"关键数据"3 行 → 中间趋势表 6-12 期 → 底部数据来源。

### 8. `read_pdf(url, offset?, limit?, format?)` — 通用 PDF 阅读 ⭐ 新增

```
Inputs:
  url: 必填,**必须是 .pdf 或 Content-Type: application/pdf**
       支持 eastmoney pdf.dfcfw.com(公告 H2_*/研报 H3_*)、巨潮、券商研报站等任意 PDF URL
  offset?: u32 default 0,字符偏移(从 PDF 提取的纯文本流中的字符位置)
  limit?: u32 default 4000,本次返回字符数
  format?: "markdown" / "text" default "markdown"
```

实现:
- 用 reqwest fetch PDF binary(stream + tempfile)
- 用 `pdf-extract` crate(纯 Rust)或 `lopdf` 解析为纯文本
- 字符 offset/limit 切片
- 输出 markdown 顶部 progress + 底部 next_offset hint

输出 markdown:
```
## PDF: <PDF 标题(从 metadata 或 URL 推断)>
**来源**: <url>
**进度**: 第 0-4000 字 / 共 ~28000 字 (4/35 页)

<extracted text 4000 chars>

---
**下一段**: `read_pdf(url, offset=4000, limit=4000)` 续读 (剩余 ~24000 字)
```

canvas display_payload 含 raw PDF metadata(title / author / total_pages / fetched_at)。

错误码:
- pdf_parse_failed → permission(不重试,model 改路径)
- url_not_pdf → validation
- fetch_failed → transient

### F. structured error 严区分

每个 tool 返:
```rust
struct ToolOutcome {
  model_output: String,         // distilled markdown ≤1500 tokens
  display_payload: Value,        // raw structured for canvas
  empty_dimensions: Vec<String>, // 哪些 focus / dimension 数据空(success,非 error)
  errors: Vec<ToolError>,        // structured errors
  sources: Vec<DataSource>,      // provenance
}

enum ToolErrorKind {
  Transient,   // retry 有效:timeout / 5xx / 网络
  Validation,  // 参数错:fix 后 retry
  Policy,      // 业务规则禁止:不重试
  Permission,  // 权限不够:不重试
  // Empty 不算 error,在 empty_dimensions 里
}
```
