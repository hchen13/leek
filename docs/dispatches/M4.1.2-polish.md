## 任务 2:`industry_landscape` 接 `concepts` focus

### 2.1 设计:行业 → 概念 fuzzy join

输入是 symbol 或 industry name。处理:
1. 若 symbol → `stock_basic` 推断 `industry`(申万行业名)
2. 取该行业 `industry` 名 → 在 `dc_concept` 全量 5000+ 概念列表里 fuzzy search,匹配名字含 industry keyword 的概念 + 取 `hot` 字段排序前 N
3. 对 top 5-10 概念,各调 `dc_concept_cons(name=<概念名>)` 拿 lead_stock + 成分股数

输出 markdown 表:概念名 / 热度 / 成分股数 / 龙头股 / 概念描述 ≤80 字。

**facts-only**:不下"这概念将启动"判断。

### 2.2 vendor 层

`tushare.rs` 已有 `dc_concept` / `dc_concept_cons` method,不用加;只用在 `industry_landscape.rs` 内部 fan-out。

### 2.3 测试

- 茅台 → 白酒行业 → 概念列表
- 冷门行业(如"煤炭洗选业")→ 概念可能少,正确 surface 而不是 fab
- 不存在 industry → empty_dimensions + 提示
