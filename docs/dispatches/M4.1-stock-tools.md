# M4.1 — A 股工具补齐(让最简单分析能 cover)

> **Dispatch spec(2026-05-26)。** M3 跑通后,user 反馈"leek 现在不能胜任哪怕最简单的 A 股分析,工具极度缺失"。M3 落地的 5 工具(market_quote / candlesticks / financials / company_info / capital_flow)只够取数据,但**散户问"这只股能不能买"必须看的几件事**没工具支撑 → agent 只能脑补 / fab / 漏说。
>
> M4.1 补 6 个常见研究必需工具。优先 tushare 主源,有 quota 限制就 eastmoney F10 / sina / web_fetch fallback,按 M3 vendor 链模式。

## 实测 gap(从 M3 跑过的 12 + T31b PM critical case 看)

| 散户问的事 | 现有工具能答? | 缺什么 |
|---|---|---|
| 这股 PE 在行业里贵不贵? | ❌ 只能给绝对数 | 同行业横向对比 |
| 公司主要赚什么钱? | 部分(company_info 一段话)| 主营业务收入分项 + 毛利率 |
| 最近有啥重大事项 / 大股东动作? | ❌ | 公告 + 大股东增减持 |
| 卖方一致预期? | ❌ 要靠 web_search 抓研报 | 一致预期(营收 / 净利 / EPS) |
| 谁是大股东? | ❌ | 前 10 大股东 + 流通股东 |
| 这股属于什么概念 / 题材? | ❌ | 概念分类 |

实测 CMP1 / DR3 都出现过 "数据不足→agent 脑补结论" 或 "company_info 拿不到→ 整段判断打折"。

## Scope

### A. 6 个新工具

每个工具按 M3 现有工具的模式实施:
- vendor 层(`crates/gateway/src/vendors/{tushare,eastmoney}.rs` 加方法)
- 工具层(`crates/gateway/src/agent/tools/get_*.rs`)
- 注册到 agent loop tool registry
- 内置 AGENT.md 描述更新
- 单测 + smoke

#### A1. `get_industry_peers(symbol, dimension?)`

- 输入:symbol(必),dimension(optional, default="valuation"):"valuation" / "growth" / "profitability"
- 输出:目标公司 + 同行业 top N(N=8-12)各家的关键指标
  - valuation:PE_TTM / PB / PS / 股息率 / 总市值
  - growth:营收增速 YoY / 净利增速 YoY / 近 3 年 CAGR
  - profitability:ROE / 毛利率 / 净利率 / ROIC
- 必返 industry / sub_industry 名称 + 行业中位数 + 目标公司行业分位
- vendor:tushare `stock_basic`(行业分类) + `daily_basic`(估值指标) + `fina_indicator`(财务指标)
- fallback:eastmoney F10 行业对比页 web_fetch

#### A2. `get_business_breakdown(symbol, period?, dim?)`

- 输入:symbol,period(default 最新年报 / 最新半年报),dim:"product" / "industry" / "region"(default product)
- 输出:主营业务收入按 dim 切分的列表:item / revenue_yuan / pct_of_total / gross_margin / yoy_change
- vendor:tushare `fina_mainbz`(主营业务构成),如果 quota 不够 fallback 到 eastmoney F10 "主营构成" 页

#### A3. `get_announcements(symbol, days?, type?)`

- 输入:symbol,days(default 30,max 365),type(optional filter,e.g. "重大事项" / "增减持" / "分红配股" / "解禁")
- 输出:每条公告 {date, title, type, url, abstract}
- vendor:tushare `anns_d`(公告 daily) 优先;fallback 巨潮资讯网 web_fetch(免费公开)
- 注意:title 截断 + 同 title dedupe

#### A4. `get_consensus(symbol)`

- 输出:卖方一致预期 -- 含未来 1-2 年营收 / 净利 / EPS 一致预期均值 + 高 / 低 / 中位 + 评级分布(buy / hold / sell 各家数)
- vendor:tushare `report_rc`(高级接口,需 5000 积分)或 eastmoney F10 一致预期页 web_fetch fallback
- 若两个 vendor 都拿不到 → 显式返回 `consensus_available: false` + reason,**禁止 fabricate**

#### A5. `get_top_holders(symbol, kind?)`

- 输入:symbol,kind:"total"(default,全部股东 top 10)/ "float"(仅流通股东 top 10)
- 输出:rank / holder_name / shares / pct_of_total / change_qoq(本季较上季的持股变动)
- vendor:tushare `top10_holders` / `top10_floatholders`(免费),fallback eastmoney F10 股东列表 web_fetch

#### A6. `get_concepts(symbol)`

- 输出:该 symbol 所属概念 / 题材列表(标签 + 概念热度排名,如有)
- vendor:tushare `concept_detail`(高级接口)或 eastmoney 概念页 web_fetch fallback
- 输出最多 30 个概念(按热度排序)

### B. 内置 AGENT.md 描述更新

新工具加进 5 个内置 AGENT.md 的 `allowed_tools` / `description` 段:

- **quick-screen**:加 `get_industry_peers`(valuation 维度,快速看贵不贵)+ `get_concepts`(quick 看题材)。**不加** announcements / consensus / business_breakdown(那是 deep-review 的活)
- **deep-review**:全部 6 个新工具都加(深度复盘自然全用)
- **comparison**:加 `get_industry_peers`(横向对比天然需要)+ `get_business_breakdown`(细分对比)
- **corpus-expert**:不加(corpus 视角,不调 A 股数据工具)
- **general-purpose**:全部加(default 都能用)

主 agent system prompt 描述同步加新工具一行说明。

### C. Vendor 层 fallback 链

按 M3 模式:tushare → sina / eastmoney → web_fetch。每次 fallback 必须 surface `data_source: "fallback-N"` + warning chip,debug_payload 留 attempts 数组。

注意:
- tushare 高级接口(report_rc / concept_detail)可能 user 没 quota -- 调用前看 token 是否有效 + quota 错误码识别,优雅退到 eastmoney
- eastmoney F10 网页结构变更风险 -- 用稳定 selector + 失败时 trace 留 HTML excerpt 方便 debug

### D. Schema / 测试

`crates/gateway/migrations/` 不需要新表(工具 invocation 已 trace 到 events / artifacts)。
单测:每个工具至少 mock vendor 成功 + mock vendor 失败 fallback 路径。

集成 smoke:跑 1 个 prompt"深度复盘茅台,用全部新工具",看 6 个工具都被 agent 调到 + 数据被 surface。
