# 东方财富非官方公开 JSON API 调研报告

调研时间: 2026-05-26 ~ 2026-05-27 (周二夜盘后, 周三盘前)
样本股票: 600519 茅台 / 300750 宁德 / 000001 平安银行
方法: chrome XHR 抓取 + curl 实测; 浏览器内 Network 截获真实 URL
**关键 hack**: push2.eastmoney.com 的 `fs` 参数中分隔符在 curl 中必须是 `%20`(URL-encoded space), 写成 `+` 或不编码空格都会 empty reply。所有 datacenter-web filter 字符串值用 `="600519"` (双引号), 单引号被 ANTLR 预处理器拒。

## 通用约定

- `push2.eastmoney.com` 实时行情 / 资金流向当日 / clist 行情排行 — REST + JSONP (cb 参数)
- `push2his.eastmoney.com` 历史 K 线 / 资金流向历史
- `datacenter-web.eastmoney.com/api/data/v1/get` — datacenter 报表 (大部分免 token)
- `datacenter-web.eastmoney.com/securities/api/data/v1/get` — 需 `token=894050c76af8597a853f5b408b759f5d` (硬编码公钥, 北向/特殊报表)
- `datacenter.eastmoney.com/securities/api/data/v1/get` — F10 报表 v1 (source=HSF10 client=PC)
- `datacenter.eastmoney.com/securities/api/data/get` — F10 报表 v0 (type=xxx sty=xxx p/ps/sr/st 短参)
- `emweb.securities.eastmoney.com/PC_HSF10/*/PageAjax` — F10 老接口, gzipped, 一次拉一整 section
- `emweb.securities.eastmoney.com/PC_HSF10/NewFinanceAnalysis/*AjaxNew` — F10 新财务专项
- `reportapi.eastmoney.com/report/*` — 研报
- `np-anotice-stock.eastmoney.com/api/security/ann` — A股公告列表
- `np-cnotice-stock.eastmoney.com/api/content/ann` — 公告详情 + 附件 PDF URL
- Referer header 强烈推荐(`https://data.eastmoney.com/` 或 `emweb.securities.eastmoney.com/`); push2 偶有强校验
- Cookie 不需要; 全公开匿名可用; UA 偶有需要(填 Mozilla/5.0 即可)

## curl 常见坑总结

1. `push2.eastmoney.com/api/qt/clist/get?fs=...` 的 fs 参数: 浏览器发 `m:90+t:2`(`+`原样), curl `--data-urlencode` 把它编码成 `%2B` 会 empty reply。**必须**: 把分隔符在 URL 里手写成 `%20`(空格) 或者用 `m:90 t:2`(浏览器对 `m:90 t:2` 也接受空格)。
2. `datacenter-web.eastmoney.com/api/data/v1/get` 的 filter 字符串值: 单引号 `'600519'` 会 ANTLR 预处理器报错; 双引号 `"600519"` 通过 (URL encoded `%22600519%22`)。日期 `=%272026-05-26%27` 单引号反而通过, 不一致。
3. `emweb.securities.eastmoney.com/PC_HSF10/*/PageAjax` 默认返回 gzip; curl 需要 `--compressed` 或显式 `Accept-Encoding: gzip`。
4. 北向 token `894050c76af8597a853f5b408b759f5d` 是硬编码公钥, 不刷新, 永久有效。
5. F10 reportName 中 `source=HSF10&client=PC` 必须带, 否则报错; `datacenter-web` 报表则用 `source=WEB&client=WEB`。
6. `push2.eastmoney.com` 路径要么走浏览器(Chrome 内 fetch CORS 会失败但页面内 jsonp `cb=jq` callback 不会), 要么 curl 配合 `Referer`; 不要省 Referer。
