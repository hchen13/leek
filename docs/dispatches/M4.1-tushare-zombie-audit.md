## 推荐使用清单(直接给 agent 暴露)

**A 类资金流向(全推荐)**:`moneyflow`, `moneyflow_dc`, `moneyflow_ths`, `moneyflow_hsgt`, `moneyflow_mkt_dc`, `moneyflow_ind_dc`, `moneyflow_ind_ths`, `moneyflow_cnt_ths`

**B 类北向(部分,加文档警告)**:
- `hk_hold` — 仅 trade_date 维度,**T-3 延迟**,不能按 ts_code 单查
- `ggt_daily` — 用默认查询拿最新 1000 日,**T-4 延迟**
- `stock_hsgt`, `hs_const` — 静态可用
- `ccass_hold`, `ccass_hold_detail` — 必须按 **ts_code 维度**查询,trade_date 单查永远空

**C 类龙虎榜(全推荐)**:`top_list`, `top_inst`, `hm_list`, `hm_detail`, `limit_list_d`, `limit_step`, `limit_cpt_list`

**D 类研报(全推荐,带节流)**:
- `report_rc`, `broker_recommend`, `research_report`, `stk_surv`
- `report_rc` 需 1 次/分钟节流

**E 类概念(部分)**:
- `dc_concept` — **首选**,字段全
- `concept` + `concept_detail` — 兜底
- `dc_concept_cons` — 必须按 **`name` 查询**

**F 类财报(全推荐)**:`forecast`, `express`, `disclosure_date`, `fina_mainbz`
- `forecast` 必须传 `ts_code` 或 `ann_date`,不能只用日期区间

## 避免使用清单(僵尸/半僵尸)

| Endpoint          | 问题                                                                                            | 替代方案                                            |
| ----------------- | ----------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| **`ggt_monthly`** | **已退役**:数据停在 2020-12,5 年未更新                                                          | 用 `ggt_daily` 自行按月聚合                         |
| `hsgt_top10`      | **2024-08 起半僵尸**:`net_amount/buy/sell` 100% null,只剩 close/amount/rank                    | 用 `hk_hold` + `moneyflow_hsgt` 组合                |
| `ggt_top10`       | 顶层 `amount/net_amount` 全 null;sh_*/sz_* 字段拆成两行,实战需后处理                            | 同上                                                |
| `dc_hot`          | `hot`/`concept` 字段 100% null,核心热度信号无效;且 1 次/小时严格限频                          | 用 `dc_concept` 按 hot 字段排序                     |
| `ths_hot`         | `hot`/`concept`/`rank_reason` 全 null,实战等同 ZOMBIE                                            | 用 `dc_concept` / `limit_cpt_list`                  |

## 给 LLM Agent 暴露的 Tool 建议(高优)

1. **个股资金面合订包**:`moneyflow` + `moneyflow_dc` + `moneyflow_ths` 给一次查询,三家口径对比
2. **市场温度**:`moneyflow_mkt_dc` + `moneyflow_hsgt` + `limit_cpt_list` 拼成一个"今日大盘 + 北向 + 涨停板"摘要
3. **行业热度**:`moneyflow_ind_dc` + `dc_concept` 排序;**不要**用 `dc_hot`
4. **个股事件**:`top_list` + `top_inst` + `hm_detail` 拼"今日异动榜"
5. **基本面研报**:`research_report` (取 url) + `report_rc` (一致预期) + `broker_recommend`
6. **业绩**:`forecast` + `express` + `disclosure_date` 用 `ts_code` 单股查询场景
