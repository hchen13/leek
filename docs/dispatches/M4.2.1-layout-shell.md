### Rail(左,vertical 48px)
- `background: var(--panel)`
- 顶部:brand mark "L"(36×36,正方形,圆角 lg)
- 主区:1 个 chat tab icon button(目前只一个 tab,以后扩展)
  - active 状态:`color: var(--accent)` + 左侧 2px `var(--accent)` indicator bar
- 底部:settings 齿轮 icon button — 点击进 Settings page(占整个 main 区)
- icon size 18-20px / button hit area 36×36 / border-radius md

### Chat 列(380px,左)
- `background: var(--bg)`
- 顶部 header:
  - **"≡ history" button**(左)— 点击触发 Session drawer 弹出
  - session 当前标题(中)
  - 新建 session button "+"(右)
- 中间:turn 流(user/assistant bubble 交替)
- 底部:composer(textarea + send button)
- chat header / footer 用 `border-bottom: 1px solid var(--border-soft)` 分隔

### Canvas 列(flex 1,中)
- `background: var(--bg)`
- 顶部:小 breadcrumb / session 标识(简洁,不要 main 分支那种假美股 NYSE 数据)
- 卡片瀑布流:Card 自下而上累积,每张 Card **变宽度**(use `max-width` CSS)
  - default `max-width: 480px`
  - 大卡(K 线 / chart_data)可全宽 `max-width: 100%`
  - 小卡(market_pulse 报价行)`max-width: 360px`
  - 用 CardShell.size: "sm" | "md" | "lg" | "xl" | "full" prop 控制
- 卡片间垂直 `gap: var(--space-3)` 12px
- 卡片**左对齐**(不是居中,因为有不同宽度)

### Sidebar(280px,右)
- `background: var(--panel)`
- 顶部:**Corpus minimap** 256×256 px 正方形
  - 类 RTS 游戏小地图样式
  - 力导向 graph 但缩为 dot(节点直径 3-4 px)
  - 本 turn 激活节点用 `var(--accent)` 脉冲(motion-pulse)
  - 历史激活节点 `var(--muted)` 透明 0.5
  - 点 minimap 全屏弹出 corpus 大图(class lk-corpus-fullscreen 覆盖 main 区)
- 中间分隔:`var(--space-3)` gap
- 下方:**Plan 列表**
  - 无 plan(`state.plan == null` 或 plan.items 为空)→ **整个 Plan 区域不渲染**
  - 有 plan 时:item 列表,每行 status dot + step text
  - status dot:in_progress 用 accent + pulse / completed 用 ok / pending 用 muted
- 整个 Sidebar:corpus 永远有(空 corpus 时显灰色 256×256 占位)+ plan 有则显
- 没 corpus 也没 plan 时(罕见)→ Sidebar 不显示,canvas 拉满

### Session drawer(从左滑入)
- Trigger:Chat header 上的 ≡ 按钮
- 宽度 320px / `background: var(--surface)` / 从左 slide in `--motion-base`
- backdrop `rgba(0, 0, 0, 0.5)` 遮 main 其他区(canvas / sidebar 仍可见)
- 内容:
  - 顶部:搜索框(`background: var(--surface-2)`,带 search icon)
  - 中间:Session list 时间分组(today / 本周 / 本月 / earlier)
    - 每条 session:title + 最近 turn 时间 + 状态点(running 脉冲 / done 静默 / fatal 红)
    - 当前 session 高亮 `background: var(--accent-tint)` + 左 2px accent bar
    - 右键 / 长按 / 点 hover 上"⋮" → 弹 popover 菜单(rename / delete)
  - 底部:**"+ 新建" 按钮**(secondary button 样式)
- 关闭:点 backdrop / Esc / 再点 ≡ button

### Settings page
- Trigger:Rail 左下齿轮 button
- 占满 main 区(覆盖 chat / canvas / sidebar 三列,Rail 还显示)
- 顶部:"← 返回 chat" 按钮(左)+ "Settings" 标题(中)
- 内容用 main 现有 Settings.tsx 字段全套(idle_timeout / wall_clock / max_iter /

### Status pill / turn 进行中
- 当 turn 在 running:Chat composer 区上方显示 pill,状态由 store.ts 现有逻辑给(M3.2)

- Settings → Theme section → toggle:dark(default)/ light
- 切换 = 设置 `<html data-theme="light">`,tokens.css 自动 cascade

## CardShell 组件 spec

```tsx
<CardShell
  size="md"            // sm 360 / md 480(default) / lg 540 / xl 600 / full
  tool="stock_overview"   // 决定 icon
  title="个股 · 600519.SH · overview"   // 来自 tool ui.summary
  status="ok"          // "in_progress" | "ok" | "warn" | "danger"
  actions={[copy, raw-toggle, expand]}   // 顶部右侧 action 按钮组
>
  {children}   // 实际渲染区,Phase 2 各工具 Card 占位
</CardShell>
```

视觉:
- `background: var(--surface)` / `border: 1px solid var(--border)` / `border-radius: var(--radius-lg)`
- header bar:`padding: var(--space-3) var(--space-4)` / border-bottom soft
- header:left icon(24px,tool 对应)+ title(14px UI weight)+ status pill + spacer + actions
- content slot:`padding: var(--space-4)`
- header click → toggle collapsed(M4.2 后做,本 phase 不实施)
- raw-toggle action click → 显示 raw JSON in `<pre class="lk-mono">` 覆盖 content

### Phase 1 时所有卡片用 `<GenericToolCard>` 占位

- 内容用 `<SafeMarkdown>` 渲染(主分支 main 已有 SafeMarkdown 实现,可借鉴)
- 底部有"显示 raw"toggle,展开看 raw JSON

## 实施约束

1. **永远不写 hex inline** — 全 `var(--*)`,新颜色必须先加 DESIGN.md + tokens.css
2. **不重复 design-system 决策** — 看 DESIGN.md §1-§9 + tokens.css
3. **不用 inline style 大量写 CSS** — 全部 class + `styles.css`
4. **变宽度卡片**:CSS class lk-card--sm / md / lg / xl / full,不要 inline width
5. **金融数字** 一律加 `class="lk-num"`(tabular-nums)
6. **涨跌色** 用 `.lk-up` / `.lk-down` 类(`--up` / `--down`),不要用 status `--ok` / `--danger`
7. **中英混排** 用 var(--font-body) 复合栈,DESIGN.md 已注释顺序
8. **dark default + light toggle** 通过 `<html data-theme="light">` 切换
9. **anti-AI-slop**(craft/anti-ai-slop.md):无 spring overshoot / 无 generic gradient
10. **state coverage**(craft/state-coverage.md):每 component 有 empty / loading / error
