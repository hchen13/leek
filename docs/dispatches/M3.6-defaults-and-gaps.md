### C. M2.6 config.merge null = clear field(不再 noop)

`crates/gateway/src/config.rs::Config::merge`:

当前 `if patch.field.is_some() { self.field = patch.field; }` 把 None 当 noop。用户 PATCH `{"cost_cap_usd": null}` 想清掉字段,实际没生效。

改成区分"absent"(JSON 不含字段)vs "explicit null"(JSON `"cost_cap_usd": null`):

```rust
// serde:`#[serde(default, deserialize_with = "double_option")]` 让 field type 是
// Option<Option<T>>,absent = None,explicit null = Some(None),value = Some(Some(x))
pub cost_cap_usd: Option<Option<f64>>,

// merge 逻辑
match patch.cost_cap_usd {
    Some(None) => self.cost_cap_usd = None,        // explicit null → clear
    Some(Some(v)) => self.cost_cap_usd = Some(v),  // value → set
    None => {}                                      // absent → noop
}
```

或者更简单:加新字段 `clear_fields: Vec<String>` 给 PATCH,显式说"清这些字段"。executor 选简单一种。

Settings UI "Reset to default" 按钮重写,用新机制清字段。

### D. T19 hooks hot reload

`crates/gateway/src/main.rs` + `crates/gateway/src/hooks/`:

当前:hooks 启动时一次性 load 进 `Arc<HookEngine>`,改 `~/.leek/config.json` 不重启 gateway 不生效。

改:hooks engine 移到 `Arc<RwLock<HookEngine>>`,settings PATCH endpoint 在写入 config.json 后调 `hooks::reload(...)`。新增 watcher 用 `notify` crate(可选,但 spec 强调"热"如不可行用 PATCH-triggered reload 也行)。

简单做法:settings PATCH 之后调用 `hooks::reload()`,即时生效。
