## Scope

### A. 主 agent reasoning_effort default 改 medium

`crates/gateway/src/agent/mod.rs`:
```rust
// 当前
pub(super) const REASONING_EFFORT: &str = "xhigh";

// 改成
pub(super) const REASONING_EFFORT: &str = "medium";
```

理由:
- xhigh 让主 agent 在直接处理大 prompt 时做大量 codex builtin search + 长 reasoning,这是 stream stability 主要触发因素
- medium 让主 agent 更"轻"行动,复杂 prompt 鼓励 model 通过 `task` 委派给 deep-review subagent
- deep-review subagent 仍 xhigh(它在隔离 context,长 reasoning OK)
- user 想要主 agent 也 xhigh 可在 Settings 调

### B. reasoning_effort 进 Settings + Config

`crates/gateway/src/config.rs::Config` 加字段:
```rust
pub reasoning_effort: Option<String>,  // "minimal"/"low"/"medium"/"high"/"xhigh", null = default
```

`crates/gateway/src/agent/mod.rs` 主 loop 不再用 hardcode `REASONING_EFFORT`,改读 `config.reasoning_effort.unwrap_or("medium")`。

`crates/gateway/src/api/settings.rs::effective_body` 暴露字段。

`frontend/web/src/Settings.tsx` 加字段(select dropdown):
- options:minimal / low / medium / high / xhigh
- default note:"主 agent 默认 medium(deep-review subagent 仍 xhigh 不受此影响)"
- hint:"xhigh 让 agent 更深思但容易撞 codex 长 stream 不稳;medium 是 leek 推荐 default;low/minimal 让简单问题快答"

types.ts + SettingsResponse.effective 同步加。

### C. AGENT.md frontmatter 加 `reasoning_effort` override

`crates/gateway/src/agents/agent_def.rs` 加字段:

`crates/gateway/src/agent/subagent.rs::apply_agent_overrides()` propagate 到 subagent loop chat call。

### D. fault-tolerant final — fatal 时 surface partial text

`crates/gateway/src/agent/mod.rs::compose_final_text` 改:
- 当前 fatal 路径只输出 fatal_reason.hint() ~80 字 system error
- 改:fatal 时优先 surface 已累计 assistant_delta text(如果 ≥ 1 个 substantive event 已 yield)+ 末尾加 fatal_reason hint 作为脚注
- 如果 0 substantive event yielded(reasoning 阶段就 fatal),仍只输出 fatal hint(无 partial 可救)

例子:
```
[partial assistant text from streamed deltas...]

[本回合中断:codex 服务返回 stream error,可在下方点击"重试本回合"或调整 Settings 中 reasoning effort 后重试]
```
