# Equity Valuation Skill

为 A 股 / 美股给出一份可被 audit 的估值判断：DCF 与相对估值互相校验，
带 Bear / Base / Bull 三情景，bear case 经过 steelman，结论附明确的失效
条件、置信度和动作边界。

这是方法论，不是工具脚本。它告诉你**该想清楚什么、用什么样的证据、
缺证据时怎么办**；具体调用顺序由 harness 决定。框架本身有自然的推进
顺序（business → financials → DCF → relative → scenarios → bear/macro
→ failure → conclusion），但这是逻辑顺序，不是必须串行执行的脚本。

## 核心原则

- **结论必须有证据回溯**：每条 claim 标记是事实（有源数据）、推断
  （由事实推出）还是推测（依赖假设）。
- **DCF 和相对估值互相 triangulate**：单条腿撑不起一个估值结论；两者
  方向冲突要解释，不能平均。
- **缺证据是常态，不是造数的理由**：用代理变量 / 情景敏感性 / 保守
  动作边界 / 等待条件来表达，并显式说明置信度因此降低。
- **Bear 必须 steelman**：最强反方决定安全边际是不是真的安全；稻草
  反方是无效反方。
- **不允许伪精确**：拿不到来源就用情景区间，不要拍脑袋写一个看起来
  权威的点估计。

## Phase 1 · 业务理解（能力圈）

进入财务表之前，先把这家公司的现金流为什么持续、为什么会失败搞清楚。
没有这一步，后面所有数字都悬空。

至少覆盖：

- **产业链 / 价值链**：公司在链条哪一环，利润池在哪。
- **需求驱动与定价机制**：客户是谁，价格怎么决定，付费意愿的耐久度。
- **渠道与库存动态**：分销结构、渠道库存周期、回款节奏。
- **竞争与替代**：直接竞争对手、替代品威胁、用户切换成本。
- **监管与政策**：相关政策、补贴、关税、认证门槛。
- **宏观敏感度**：消费/信用周期、地产/财富效应、利率、汇率，是否会
  实质改变现金流或估值倍数。

如果 corpus 已沉淀这家公司或行业的分析，优先复用。如果没有，本轮
session 内**建立临时能力圈**：基于一手公告、监管披露、行业贸易刊物
等可追溯来源。能力圈缺口不是拒绝任务的理由——把它写下来，标置信度，
继续。

如果连一份可信的临时能力圈都建不起来，那也建不起一份可信的估值。
这种情况要说明，而不是把财务表伪装成对业务的理解。

## Phase 2 · 历史财务质量

财务历史回答"过去经营怎么样"，不直接回答"业务是不是耐久的"。财务
质量是必要条件，不是充分条件。

每个维度都用**数字**回答，不用形容词；任何异常都要标出来：

- **营收增长的耐久度**：3-5 年 CAGR、趋势形态、波动来源。
- **自由现金流 margin / FCF 增速 vs 营收增速**：FCF 增速持续慢于营收
  增速时，留意是否 capex 或营运资金在吞利润。
- **ROE / ROIC 水平和趋势 / 资本密集度**。
- **盈利质量**：净利润对经营性现金流的转化率；应收账款增速 vs 营收
  增速；存货周转。
- **杠杆与再融资风险**：资产负债率、利息覆盖倍数、债务到期墙。
- **异常信号**：FCF 转负、ROE 骤降、应收激增、营运资金大幅波动、
  非经常性损益异常占比。

把数字同时放在两面镜子前看：和同行比，和这家公司自己的历史比。两
面镜子都给出有意义的基线。

## Phase 3 · DCF（内在价值视角）

DCF 是一种 discipline，不是 oracle。结果只配它最弱的输入那么可信。

**DCF 可信度闸（必做）**：

输出每股内在价值之前，先把每个关键输入逐项标注是**事实 / 有来源参数 /
情景假设**。关键输入必须包括：

- FCF 基期、5 年增长路径
- WACC（含无风险利率、市场风险溢价、Beta、债务成本、税率、资本结构）
- 永续增长率
- 净有息债务、总股本

各输入的来源要求：

- **无风险利率**：当前同币种 10 年期主权债收益率，标注来源与日期；拿不
  到来源时只能作为情景假设。
- **市场风险溢价**：来自可追溯来源（市场隐含 ERP、Damodaran、券商/
  交易所/监管统计等）并标注日期；缺源时输出敏感性区间，不静默套默认。
- **Beta**：优先可追溯行情/数据源；缺失时用同行样本反推区间，并标注
  为估计值。
- **债务成本**：取最近借款利率、债券收益率或财报披露的利息成本；缺
  失时用情景区间，不用未说明来源的"行业平均"。

如果多项关键输入缺源，那这就不是"DCF 内在价值"——它是一份**情景敏感
性练习**。要在标题就说清楚，不要让它伪装成事实。

**FCF 预测**：

- Year 1-2：锚定近 2 年 FCF 均值增速；上限取赛道现实水位（多数情况
  ≤ 25%），明显异常的高增长要单独论证。
- Year 3-5：朝长期可持续水平衰减。
- 长期持续高于行业 / 经济名义增长的增长路径，必须给出可证伪的论据。

**Terminal Value**：

- 永续增长率必须低于长期名义 GDP 或行业成熟期增长上限；具体值要么
  来自来源层，要么作为 Bear/Base/Bull 假设。
- TV = FCF₅ × (1 + g) / (WACC - g)。

**汇总**：

- EV = Σ FCFₜ / (1+WACC)ᵗ + TV / (1+WACC)⁵
- Equity = EV − 净有息债务
- 每股内在价值 = Equity / 总股本

**Sanity check**：

- TV 占 EV 50–80% 之间；过高 → 检查 g 和 WACC，过低 → 检查近端 FCF
  是否被高估。
- EV 与当前市值偏离超过 50% 时不直接拒绝结论，但必须解释偏离的来源
  （增长假设、折现率、资本结构变化等）。

## Phase 4 · 相对估值

DCF 给你内在价值，相对估值告诉你**市场是否同意，以及理由可能是什么**。

挑至少 3 家同行业、相近规模的可比公司，比较：

- P/E TTM 和（如有可信预测）forward
- P/B
- EV/EBITDA
- P/FCF

每个倍数都要标注输入数据的日期。结论需要回答：

- 标的处于溢价 / 折价 / 合理区间，幅度多少。
- **最 plausible 的解释**是什么——增长差、质量差、风险差、还是市场
  错配。如果给不出可信的解释，就把它标为待澄清的 discrepancy，而不
  是一个 verdict。

## Phase 5 · 情景综合

把 DCF 与相对估值统一成 Bear / Base / Bull 三情景。每个情景必须写明
**触发条件**（怎样的可观测事件会让这个情景演出）。

| 情景 | 核心假设 | 每股内在价值 | 触发条件 |
|------|----------|-------------|---------|
| Bear | … | … | … |
| Base | … | … | … |
| Bull | … | … | … |

把当前价格与 Base 比较，算出溢价 / 折价百分比，并就**安全边际**给出
判断（充足 / 偏薄 / 不足）。

## Phase 6 · 多空 / 宏观 / 资金面

**Bull case（2-4 条）**：每条对应可观测的触发事件，不是"看好增长"。

**Bear case（2-4 条，steelmanned）**：必须包含：

1. 当前估值本身的下行风险（即使业务不变，估值收缩会带来的损失）。
2. 一条结构性竞争 / 行业风险。

弱版本的反方等于没反方。

**宏观传导**：现金流如果对消费 / 信用周期、地产 / 财富效应、政策、
利率、汇率敏感，必须显式描述传导链条——宏观变量怎样影响销量、价格、
利润率、折现率或估值倍数。"宏观不好"不是传导。

**资金面 / 市场结构信号**（如果有）：说明它代表什么——拥挤度、短期
情绪、流动性、退出压力，还是与基本面分歧。这类信号只影响入场 / 退出
和短期风险，不能替代内在价值判断。

## Phase 7 · 失效条件

下结论之前，写下这套 thesis 在什么条件下应该被推翻。具体要回答：

- 哪个假设错多少时，结论就不成立。
- 哪个可观测事件，到什么时点没出现，thesis 应该降级。
- 什么变化会把判断从"低估"翻成"合理"或"高估"。

没有失效条件的 thesis 是不可证伪的，不应该用来驱动决策。

## Phase 8 · 结论

输出结构：

```
**[股票名称 / 代码]  估值结论**

DCF 内在价值区间：XX – XX 元（Bear / Base / Bull）
DCF 参数表：FCF 基期 / 增长路径 / WACC / 永续增长率 / 净有息债务 / 股本数 / 来源层级
相对估值隐含价格：XX 元（中位数）
当前价格：XX 元 → 相对 Base 溢价 / 折价 XX%

**判断**：[高估 / 合理 / 低估]，安全边际 [充足 / 偏薄 / 不足]，置信度 [高 / 中 / 低]

**核心论点**（≤100 字）：为什么贵 / 便宜 / 合理。

**最重要的不确定性**（1-2 条）：什么信息能改变上述判断。

**失效条件**：什么会让这套 thesis 失效。

**信息层级**（discipline §1）：
- 事实：[数据来源]
- 推断：[基于上述数据推出的结论]
- 推测：[依赖假设的部分]
```

## 缺证据时怎么思考

证据不足是常态，不是造数据的理由。处理方式：

- **代理变量（proxy）**：拿不到直接指标时，挑一个会跟着它一起动的代理，
  显式说明你用它代理什么。例：渠道库存不透明时，用客户端订货节奏和应收
  账款行为做代理。
- **情景敏感性**：把缺失参数的合理区间穿过模型，看结论怎么变。给一段
  区间，不给虚假精确的点估计。
- **保守动作边界**：不确定性高的合理动作是**缩仓位**，不是降低分析
  标准。把动作边界写出来：在什么置信度下，至多 X% 仓位。
- **等待条件**：写明哪类数据出现后能升级结论。这是"我现在不知道"和
  "我会在 X 之后知道"的区别。
- **缺口与置信度的精确关联**：缺无风险利率和缺资金面信号是不同的事；
  分别说明缺口具体削弱了哪些输入、哪些结论。

如果一个关键输入彻底缺失而又找不到可接受的代理，正确的输出是**一份
calibrated 的半成品**——一份带明确缺口和动作边界的情景敏感性练习——
而不是一个伪装成自信的判断。
