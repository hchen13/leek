# Equity Valuation Skill

对 A 股或美股进行系统性估值，强制执行双轨（DCF + 相对估值）、三情景输出。

## 必须遵守的执行顺序

每步为必做项，不可跳过、不可合并、不可替换为泛泛描述。

---

### Step 1 · 基础数据拉取

**计划纪律：**
- 调用本 skill 后，先用 `update_plan` 的 `plan` 参数建立本轮估值研究计划。计划至少覆盖：corpus/knowledge 检索、临时 working model、财务质量、估值、反方、风险与结论。
- 每完成一个阶段就调用 `update_plan` 更新状态和 evidence。active plan 未全部完成前不得输出最终估值结论。

**能力圈与 knowledge 覆盖检查：**
- 先用 `corpus_search` 查询标的公司、行业、产业链和关键产品。若 knowledge 层没有覆盖，不得直接宣称“在能力圈内”。
- knowledge 缺口不是拒绝任务的理由。你必须在本 session 建立临时能力圈，并把它标注为 working model。
- 临时能力圈至少包括：产业链/价值链、需求驱动、价格机制、渠道库存、竞争/替代品、监管政策、宏观消费/信用周期、资金面/流动性。
- 若 corpus knowledge 未命中公司/行业，必须使用 `web_search` 做外部事实核验，
  至少覆盖行业状态、价格/渠道、宏观或政策变量、主要竞争者；必要时再用
  `web_fetch` 打开关键来源。不能只列出这些维度然后停止。
- 若用户禁止联网，只能用当前工具做受限临时能力圈；必须把缺口写在结论前，而不是用财务表替代产业理解。

**A 股：**
- `get_company_info` → 获取行业分类、上市日期、注册地
- `get_financials` → 过去 4 年年报（revenue、operating_income、net_income、fcf、total_assets、total_debt、equity、eps、dividends）
- `market_quote` → 当前股价、市值、52 周高低（如行情源不可用则标注缺口）
- `get_candlesticks` → 近 1 年周 K 线（判断趋势 + 均值回归位置）
- `get_capital_flow` → 近期主力资金净流向

**美股：**
- `get_company_info` → 行业、sector
- `get_financials` → 过去 4 年（同上字段）
- `market_quote` → 当前报价、market cap、技术评级
- `get_candlesticks` → 近 1 年周 K 线
- `sec_filing_fetch` → 最新 10-K（或 10-Q）摘要，重点找 management outlook + risk factors

如有 corpus 相关文档，同步调用 `corpus_search` 以拉取已沉淀的行业 / 企业分析。

### Step 2 · 历史财务质量评估

财务质量只能回答“过去经营结果如何”，不能单独证明业务可理解。进入财务表之前，先给出临时能力圈摘要：

| 维度 | 已知事实 | 仍缺什么 | 对估值的影响 |
|------|----------|----------|--------------|
| 产业链 / 价值链 | _填入_ | _填入_ | _填入_ |
| 需求 / 价格 | _填入_ | _填入_ | _填入_ |
| 渠道 / 库存 | _填入_ | _填入_ | _填入_ |
| 竞争 / 替代 | _填入_ | _填入_ | _填入_ |
| 宏观 / 政策 | _填入_ | _填入_ | _填入_ |
| 资金面 / 流动性 | _填入_ | _填入_ | _填入_ |

在进入估值计算前，必须完成以下判断（每项给出具体数值，不只是形容词）：

| 指标 | 目标水平 | 实际情况 |
|------|----------|----------|
| 营收 CAGR（3 年） | 依赛道 | _填入_ |
| 自由现金流 CAGR（3 年） | > 营收 CAGR | _填入_ |
| FCF margin | > 10% 为健康 | _填入_ |
| ROE 平均 | > 15% 为优秀 | _填入_ |
| 净利润 / 经营利润转化率 | > 80% | _填入_ |
| 资产负债率 | < 60% 优先 | _填入_ |

标记明显异常（FCF 连续为负、ROE 骤降、应收账款增速远超营收增速等）。

### Step 3 · DCF 估值（五年展望法）

**DCF 可信度闸：**
- 禁止输出黑箱 DCF 区间。任何每股内在价值区间前，都必须先列出 FCF 基期、5 年增长路径、WACC、永续增长率、净有息债务、股本数，以及每个输入是“事实 / 有来源参数 / 情景假设”。
- 若无风险利率、市场风险溢价、Beta、债务成本或股本数缺失，结论只能写成“情景敏感性估值”，不得写成事实性的 DCF。
- 不得静默使用默认宏观参数。所有默认值都必须显式标注为假设，并说明为什么该假设保守或激进。

**WACC 计算：**
- 无风险利率：必须使用当前同币种 10 年期主权债收益率，并标注来源与日期；拿不到来源时只能作为“情景假设”，不能写成事实。
- 市场风险溢价：必须来自可追溯来源（市场隐含 ERP、Damodaran、券商/交易所/监管统计等）并标注日期；拿不到来源时输出敏感性区间，不能静默套默认值。
- Beta：优先使用可追溯行情/数据源；缺失时用同行样本反推区间，并把它标注为估计值。
- 债务成本：取最近借款利率、债券收益率或财报披露的利息成本；缺失时用情景区间，不得用未说明来源的行业平均。
- WACC = Ke×E/(D+E) + Kd×(1-t)×D/(D+E)

**FCF 预测（5 年）：**
- Year 1-2：锚定近 2 年 FCF 均值增速，上限 25%
- Year 3-5：每年衰减 20%（例：25% → 20% → 16% → 13%）
- 超过行业 DDM 长期增速 5% 以上须额外说明理由

**Terminal Value：**
- 永续增长率：必须低于长期名义 GDP / 行业成熟期增长的合理上限；具体数值必须说明来源或作为 Bear/Base/Bull 情景假设。
- Terminal Value = FCF₅ × (1 + g) / (WACC - g)

**折现求和：**
- 企业价值 EV = Σ FCFₜ/(1+WACC)ᵗ + TV/(1+WACC)⁵
- 权益价值 = EV - 净有息债务
- 每股内在价值 = 权益价值 / 总股本

**Sanity check（必须通过）：**
- Terminal Value 占 EV 比重 50-80%；否则检查 g 和 WACC 输入
- EV 与当前市值偏差 > 50% 须重新核查假设

### Step 4 · 相对估值

拉取至少 3 家同行业、相近市值竞品，对比以下倍数（数值必须标明来源时间）：

| 指标 | 标的 | 竞品均值 | 溢价/折价 |
|------|------|----------|-----------|
| P/E（TTM）| | | |
| P/E（NTM，若有分析师预测）| | | |
| P/B | | | |
| EV/EBITDA | | | |
| P/FCF | | | |

结论：标的在相对估值维度处于**溢价/折价/合理**区间，百分比偏差是多少。

---

### Step 5 · 综合估值区间

将 DCF 与相对估值结果对齐，得出三情景目标价：

| 情景 | 核心假设 | 内在价值（每股） | 触发条件 |
|------|----------|-----------------|----------|
| Bear | FCF 增速 -20%，WACC +1%，竞品折价 | X 元 | 需求下滑 / 竞争加剧 / 宏观收紧 |
| Base | Step 3 中性假设 | X 元 | 维持当前增长节奏 |
| Bull | FCF 增速 +20%，WACC -0.5%，竞品溢价 | X 元 | 新产品/新市场突破 |

当前价格 vs. Base 价值：溢价/折价 X%，安全边际是否充足。

---

### Step 6 · 催化剂与风险

**多方（Bull case 的支撑）：**  
列 2-4 条，每条对应可观测的触发事件（不是泛泛的"增长预期"）。

**空方（Bear case 的压力）：**  
列 2-4 条最强版本反方论点（steelmanned，不是稻草人）。
必须包含：①当前估值本身的下行风险；②竞争/行业结构性风险。

**Dalio / 宏观传导：**
若标的现金流受消费周期、信用周期、地产/财富效应、政策约束、利率或汇率影响，必须说明宏观变量如何传导到销量、价格、利润率、折现率或估值倍数。不能只写“宏观不好”。

**资金面解释：**
`get_capital_flow` 结果必须回答它代表什么：拥挤度、短期情绪、流动性、退出压力，还是和基本面分歧。资金面只影响入场/退出和短期风险，不得替代内在价值判断。

---

### Step 7 · 投资结论

结构化输出，格式如下：

```
**[股票名称 / 代码]  估值结论**

DCF 内在价值区间：XX - XX 元（Bear/Base/Bull）
DCF 参数表：FCF 基期 / 增长路径 / WACC / 永续增长率 / 净有息债务 / 股本数 / 来源层级
相对估值隐含价格：XX 元（中位数）
当前价格：XX 元 → 相对 Base 溢价/折价 XX%

**判断**：[高估 / 合理 / 低估]，安全边际 [充足 / 偏薄 / 不足]

**核心论点**：（≤100 字，说清楚为什么贵/便宜/合理）

**最重要的不确定性**：（1-2条，说清楚什么信息能改变上述判断）

**信息层级**（discipline §1）：
- 事实：[数据来源]
- 推断：[基于上述数据推出的结论]
- 推测：[依赖假设的部分]
```
